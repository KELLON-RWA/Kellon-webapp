# Kellon homepage feature assets

Three individually generated, transparent PNG product illustrations for the section below the completed hero. Created with the built-in image-generation tool. These are illustrative UI previews, not captures of the current product. The send amount is example data; the artwork does not promise rates or settlement times.

## Files

- `01-buy-deposit.png`: Buy or deposit stablecoins.
- `02-send-withdraw.png`: Send and withdraw.
- `03-invest-yield.png`: Invest and explore yield.
- `PROMPTS.md`: Exact generation prompts and reference.
- `INTEGRATION-PROMPT.md`: Copy-paste implementation prompt for Codex.

## Recommended use

Keep all website headings, descriptions, navigation, and the risk note as live HTML. Use the PNGs only as supporting artwork. Preserve transparency and aspect ratios; use equal artwork frames with object-fit: contain. Never crop the panel or stretch an image. The visible controls inside the images are illustrative, not interactive.

Real product screenshots or coded UI previews are preferable when exact interface fidelity is required. Before publishing, verify that the depicted features and available payment methods match the actual supported product and markets.

For production, create optimized WebP/AVIF derivatives that retain alpha, using the existing site's image pipeline. Retain these PNG sources. Add explicit width/height and concise alt text. Only images below the first viewport should be lazy-loaded.

No website source was modified by creating this asset pack.
